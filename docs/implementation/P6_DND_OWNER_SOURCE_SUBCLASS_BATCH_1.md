# P6 DND Owner-Source Subclass Batch 1

## Scope

The local DND 2024 owner source now supplies display-level subclass facts for:

- Fighter: Champion compatibility entry, Battle Master, Eldritch Knight, and
  Psi Warrior.
- Cleric: Life, Light, Trickery, and War domains.

Each entry records its source-matched unlock level and the named feature levels
needed by character creation and level-up preview. The pre-existing
`冠军武士` display name is retained for saved-character compatibility; the local
source names that subclass `勇士`.

## Boundary

This is reference data for selection and preview only. It does not execute
features, create spell lists or resource pools, evaluate a target, apply damage
or healing, or automate subclass choices in a Room Runtime.

Other legacy subclasses remain untouched until their own local source pages are
extracted and reviewed.
