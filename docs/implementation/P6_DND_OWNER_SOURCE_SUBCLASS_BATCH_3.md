# P6 DND Owner-Source Subclass Batch 3

## Scope

The local DND 2024 owner source now supplies display-level subclass facts for:

- Paladin: Devotion, Ancients, Vengeance, and Glory oaths.
- Ranger: Hunter, Beast Master, Fey Wanderer, and Gloom Stalker compatibility
  entry.

The pre-existing `幽域追踪者` display name is retained for saved-character
compatibility; the local source names that subclass `幽域追猎者`.

## Boundary

This is selection and level-up preview data only. It does not automate Channel
Divinity, smites, companion placement or turns, spellcasting, targeting,
damage, healing, or Room Runtime authority. The existing Oathbreaker entry is
not changed by this source batch.
