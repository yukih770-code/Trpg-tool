# P6 DND Owner-Source Subclass Batch 2

## Scope

The local DND 2024 owner source now supplies display-level subclass facts for:

- Monk: Open Hand compatibility entry, Shadow compatibility entry, Mercy, and
  Elements compatibility entry.
- Druid: Land, Moon, Sea, and Stars circles.

The old display names `散打宗`, `暗影宗`, and `四象宗` remain for saved-character
compatibility; the local source names them `散打武者`, `暗影武者`, and `四象武者`.

## Boundary

This batch records selection and level-up preview facts only. It does not
automate Focus Point spending, Wild Shape, healing, damage, spell preparation,
targeting, or Room Runtime effects. The older Spore Circle entry remains
untouched until it has a matching local source review.
