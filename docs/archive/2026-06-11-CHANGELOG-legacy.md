# 开发者日志 (Developer Log)

## [v1.1.0] - 2024-05-06

### 新增功能 (New Features)
* **角色导入/导出系统**:
  * 新增角色存档导出为 JSON 文件的功能，方便本地备份。
  * 新增从 JSON 文件导入角色的功能。
  * 根据当前选择的规则系统（D&D 或 CoC），自动判断并导入/导出对应的角色卡数据结构。

### 克苏鲁的呼唤 (Call of Cthulhu) 更新
* **调查员背景与资产扩展 (CoCSheet.tsx)**:
  * 完整实装了调查员的“背景故事 (Backstory)”板块，包含形象描述、思想与信念、重要之人、意义非凡之地、珍视之物、特征、伤痕与疤痕、恐惧症与躁狂症、奥术典籍与法术、以及遭遇克苏鲁神话之人等详细设定字段。
  * 实装了“随身物品 (Inventory)”文本域。
  * 实装了“资产状况 (Cash & Assets)”板块，包含消费水平、现金和资产记录。
* **跑团记录与检定功能加强 (CocGameplay.tsx)**:
  * 在游玩界面添加了直接操作“理智 (SAN)”和“魔法 (MP)”增减的快捷按钮。
  * 增加了“理智检定 (Sanity Check)”的快捷掷骰按钮，结果将自动与当前 SAN 值对比并生成日志记录。

### 修复与优化 (Fixes & Improvements)
* **代码修复**: 修复了 `CocGameplay.tsx` 和 `App.tsx` 中的 JSX 语法及变量重复声明导致的白屏问题。
* **UX/UI 调整**: 优化了部分输入框的样式和体验。
